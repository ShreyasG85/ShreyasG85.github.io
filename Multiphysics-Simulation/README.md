# Multiphysics Simulation Models

| File | Description |
|------|-------------|
| `CrossCapacitanceESPhysics.mph` | Finding Transmon qubit Island parameters using Electrostatics model |
| `CrossCapacitance_ECPhysics.mph` | Finding Transmon qubit Island parameters using Electric Current model |
| `CuAl.mph.zip` | Finding resistance in the interface between micron sized Copper and Aluminum blocks through simulation |
| `FullChipSim.son` | Detecting change in Kinetic Inductance of device under test (Graphene) through change in resonant frequency of cavity connected to the device |
| `LISA_PF_Charging.mph` | Demonstrate effects of electrostatic charging in the test masses of LISA Pathfinder in space |
| `LowPassFilter.son` | A simulation check to ensure the cut-off frequency of a Low Pass filter works as intended |
| `MEMS_Picket_StructureAnalysis` | Simulation Analysis of simple MEMS device |
| `NeutralAxis_MicroCantilever.mph.zip` | Comparing Numerical vs Analytic solution of finding Neutral Axis |
